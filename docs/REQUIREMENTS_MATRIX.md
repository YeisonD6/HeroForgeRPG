## 2. Conciliación de Nombres entre Secciones del PDF

1. **`applyBuildPreset` vs `applyPreset`**: Se implementa `applyBuildPreset` como reducer principal y se exporta también el alias `applyPreset = statsSlice.actions.applyBuildPreset`.
2. **`clearEquipment` vs `unequipAll`**: Se implementa `clearEquipment` como reducer principal y se exporta también el alias `unequipAll = inventorySlice.actions.clearEquipment`.
3. **Selectores individuales vs `selectHeroComputedStatus`**: Se exportan los 5 selectores individuales memoizados (`selectTotalStats`, `selectTotalWeight`, `selectIsOverencumbered`, `selectCombatPower`, `selectHeroVisualClass`) además de `selectHeroComputedStatus`.
4. **Nombres de Clases Visuales del Héroe**: `selectHeroVisualClass` retorna tanto `className` (`Novato`, `Berserker Implacable`, `Archimago Arcano`, `Asesino Sombrío`, `Tanque Pesado`) como `archetype` (`Aldeano`, `Guerrero Berserker`, `Archimago`, `Pícaro Sombrío`, `Guardián de Titanio`).
